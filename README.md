# Loon

## Lists

- [`Filters/filters_block.list`](Filters/filters_block.list) — 封鎖廣告及追蹤器網域。
- [`Filters/filters_correction.list`](Filters/filters_correction.list) — 修正 Bilibili HTTPDNS 誤封。
- [`Filters/filters_direct.list`](Filters/filters_direct.list) — 適合直接連線的服務。
- [`Filters/filters_assigned.list`](Filters/filters_assigned.list) — 需要自行指定分流策略的服務。
- [`Filters/filters_macau.list`](Filters/filters_macau.list) — 適合澳門節點的服務。

## Plugins

- [`Rewrite/Adrewrite.plugin`](Rewrite/Adrewrite.plugin) — 自行維護的廣告封鎖、Google 搜尋及 Wikipedia 重新導向規則。
- [`Rewrite/Youtube/YouTube.Enhance.plugin`](Rewrite/Youtube/YouTube.Enhance.plugin) — YouTube 與 YouTube Music 功能增強、廣告移除及字幕／歌詞翻譯。
- [`Rewrite/Advertising.plugin`](Rewrite/Advertising.plugin) — 合併的廣告封鎖及重新導向規則。
- [`Rewrite/GeneralAdBlock/GeneralAdBlock.plugin`](Rewrite/GeneralAdBlock/GeneralAdBlock.plugin) — 網站及 App 回應內容去廣告。
- [`Rewrite/Bilibili/Bilibili.Enhance.plugin`](Rewrite/Bilibili/Bilibili.Enhance.plugin) — Bilibili 介面自訂、廣告移除及推薦內容整理。
- [`Tools/CTMUsage/CTMUsage.plugin`](Tools/CTMUsage/CTMUsage.plugin) — 手動查詢 CTM 用量及餘額，預設每 15 分鐘自動更新。
- [`Tools/NetworkInfo/NetworkInfo.plugin`](Tools/NetworkInfo/NetworkInfo.plugin) — 手動查詢目前路由或所選節點的地區、供應商及公網 IPv4。
- [`Tools/NodeOfflineMonitor/NodeOfflineMonitor.plugin`](Tools/NodeOfflineMonitor/NodeOfflineMonitor.plugin) — 定時檢查節點，確認離線或恢復後通知。
